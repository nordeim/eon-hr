## The round's traps

**The between-call process reap (the standing class, round three).** The nohup'd :3200 boot died silently between two bash calls (the log showed a clean "Ready"); the standing cure — the node-spawn detached protocol (`scripts/boot3200.mjs`) — survived. The reap now has a documented three-strike record: setsid, nohup, and any shell-child form all die; only the detached node-spawn with an explicit env survives.

**The agent-browser snapshot's attribute form.** The snapshot lines carry composite attribute lists — `combobox "Select Job Position" [expanded=false, ref=e60]` — so a match regex written for `[ref=…]` alone never fires; the form is `\\[[^\\]]*ref=(\\w+)\\]`. The same lesson as the r100 accessible-name leading space: read the RAW snapshot before writing the regex.

**The fixture-guard honesty rule (the r97 lesson, fifth application).** A font-chain fixture whose yield is "A A" dies at the 40-alnum guard — the RED fires for the WRONG reason (the guard, not the decode). Every discriminating fixture must clear the guard on BOTH sides of the mutation so the assertion fires on the behavior under test.

**The upload surface's conditional render.** The AI CV Upload tab renders its file input ONLY after a job is selected ("Select a job position above to start uploading CVs") — an upload probe that fails to complete the combobox flow finds no input at all; the symptom (Element not found: input[type=file]) points at the combobox step, not the input.
