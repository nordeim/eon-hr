## The round's traps

**The port that lied.** The environ-based kill skipped the old :3200 server (its `/proc/PID/environ` unreadable), the new boot's health check answered from the OLD process still holding the port, and every "post-fix" read in the round — tab clicks that would not switch, a rate limiter that "survived" a reboot, a login-probe flow that misbehaved — was silently hitting the PRE-FIX build. The cure: kill by the PORT HOLDER (`ss -tlnp` → the pid → the parent spawn). A boot's "SERVER UP" proves nothing about WHICH server answered.

**The fixture that proved nothing.** The F-name-collision fixture's first draft PASSED before the fix existed — its raw objects were missing `<< >>` dict brackets, so the `objToTu` scan never engaged, the chain never ran, and the global first-covering fallback produced the correct answer by accident. The M2 mutation had NO teeth until the brackets landed. A fixture for a scoping fix must be audited for the engagement of the scoped path — a green that rides the fallback survives the mutation proof until the fallback itself drifts.

**The fresh-session viewport drift.** `set viewport` on a fresh session is lost when the browser relaunches — the first deploy-watch capture came out 1280×577 and read as a 12.9%-pixel DIFF against the 1440×900 baseline. The VERIFIED-VIEWPORT guard (re-apply + verify `window.innerWidth` after every open) cured it to byte-identical. A visual diff is only evidence at a viewport you have verified, not one you have requested.

**The ref-session cookie lapse.** The verify-r49 ladder's "ref" named session profile carried a lapsed auth cookie — every REF route read bounced to /login and the ladder read 0/13 all-DIFF (the r78 systematic-bounce class). The cure: re-auth the named session, re-run. A standing-ladder run that reads ALL-DIFF is a login bounce until proven otherwise.

**The scorer's whitespace-blind tokenizer.** The word-per-line defect does NOT change the E2E score — the tokenizer splits on `/[^a-z0-9+#]+/` and newlines are whitespace. The E2E teeth for a separator-class fix must come from a decode-class mutation (the font-chain leg) or ride the unit layer (the documented split).
