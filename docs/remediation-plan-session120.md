## THE FIX

### R120-A — the indirect width-array resolution
`readWidthsFromFontBody` records `/Widths N 0 R` and `/W N 0 R` refs
(with the font body's /FirstChar//MissingWidth//DW defaults); a deferred
pass after the stream walk resolves each target from the ObjStm entry
bodies (kept in a new `objstmBodies` map) or a targeted bracket-balanced
raw scan (`N 0 obj [ … ]` — balanced because /W arrays nest), then parses
into `objWidths` (the /W triple form through the standing
`parseWidthsArray`, the /Widths number list indexed from /FirstChar).
Strictly additive: a real inline array wins (`objWidths.has`
short-circuit); an unresolvable target leaves the font blind (the
conservative guard).

### R120-B — the general-name font bindings
A `fontPairsOf(body)` helper — (a) the pairs inside any `/Font << … >>`
region (the R108-B general-name discipline), (b) a body that IS a pure
pair dict (the WeasyPrint referenced-font-dict form) — feeding
`objFonts`/`pageFonts`/`fCandidates` in the raw pass's else-branch, the
ObjStm page branch, and the ObjStm else-branch (alongside the F-prefixed
scans, never replacing them).

### R120-C — the widthFor pageMap-less fallback
A part with NO page map at all resolves through the candidate chain's
first width-carrying object (position-sorted — the ownChainFor
discipline). A page map that EXISTS but lacks the font stays blind — the
misbind signal (the fontspec collision class), never a fallback license.

### R120-D — the kern-sign fix
`adv -= (kv / 1000) × ps` — the TJ displacement is negative (ISO 32000-1
§9.4.3). Cures the phantom-gap class; the Typst/arXiv accurate trackings
move sub-em (the r119 4.80 → 4.87 vs the true 4.99).

### R120-E — the leader-run guard (R118-A)
An anchor followed on the same baseline by the SAME anchor text at a
regular forward step (0 ≤ step ≤ 3 em — the same-block fontspec/dvipdfmx
run AND the per-dot repositioned IRS pieces) is a typographic LEADER —
never a split. The Typst contacts icons lead different content (the phone
digits, the email) — the icon class keeps firing.

### R120-F — the Tw/Tz advance tracking
The walk tracks the `Tw`/`Tz` text-state operators (two new regex arms)
and stamps them on pieces; the post-pass adds Tw to every single-byte
0x20 code's advance and scales all advances by Tz/100 (ISO 32000-1 §9.3).

### The interplay
The R117-A ≥ 2.5 em class, the R118-A ≥ 0.95 em class, the R116-A
line-move rule, and the R115 collapse family all stand verbatim — the
cures make the machinery SEE (the width tables, the bindings) and measure
TRUE (the signs, the state), and the one new guard (R120-E) protects the
newly-visible leader population.
