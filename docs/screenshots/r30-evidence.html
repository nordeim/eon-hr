Probe-tooling lessons this round

1. Text-only DOM censuses miss icons. REF's /assets empty state showed "No assets yet" with an 80px gap above it — the gap was a 64px slate-300 Inbox icon + mb-4, invisible to a text-node census (the subtree's kids:2 was the tell). Always read child COUNT + geometry, not just text.
2. CDP touch dispatches need animation settling + inter-phase frames. A touch that lands during the drawer's 500ms enter animation targets the OVERLAY (the panel hasn't slid under the finger yet — the Content's sibling, so the React handlers never see it), and back-to-back dispatches drop the touchMove (the round-26 separate-evals lesson, touch edition). Wait out the animation + ~100ms between phases.
3. Radix's portal renders the overlay and the panel as SIBLINGS — a "find the overlay's children" probe returns nothing; locate the panel by its own geometry (fixed, w 200–340, h≥800, non-overlay bg).
