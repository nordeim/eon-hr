Probe-tooling lessons this round

1. agent-browser's set media supports only dark|light|reduced-motion — print emulation is NOT available at the CLI layer (matchMedia("print").matches stays false); it lives in the Playwright layer via page.emulateMedia({ media: "print" }). This is why the print verification is a permanent E2E spec rather than a CLI probe.
2. The FIRST body>div is Next.js's hidden bootstrap div — the app root (min-h-screen) is a later sibling; locate it as body > div.min-h-screen, not body > div (a probe read the hidden div's min-height 0px as a false-positive proof).
3.
