The lesson: a gate proves the tree at the moment it runs; artifacts committed after the last gate run are ungated.

**The sub-em split prefix (the E2E fixture's first draft).** A 1-char split prefix ("s|ystems") kills the keyword under the scorer's 4-char prefix rule — but it is also sub-em, so the continuation rides the standing join and never touches the conditional (M2 had no E2E teeth).
